# MATW Sacrifice Landing Page Concept

A story-led React/Vite landing page based on the supplied sacrifice wireframe.

## Facts and source boundaries

- Prices and product locations were checked against MATW's official global appeals page in July 2026.
- Aqeeqah/Nidr program and reporting wording come from MATW's official Aqeeqah page.
- The 30-country, 2M people per year, and 96M meals figures are explicitly labelled as figures from MATW's published 2023 Achievements Report.
- The 100% Donation Policy copy includes MATW's merchant/banking fee and reinvestment qualification.
- No donation payment is processed by this prototype. Calls to action continue to MATW's official website.

```powershell
npm install
npm run dev
```
